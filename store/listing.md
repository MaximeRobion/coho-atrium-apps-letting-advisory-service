# Full name

Lettings Advice Service

# Short name

Lettings Advice

# Intro description

Browse Julie’s lettings advice documents and chat with the advice team without leaving COHO.

# Full description

A COHO Atrium web app that embeds the Lettings Advice Service Tawk.to chat and a Documents catalogue (guides, free templates, and videos scraped from Julie’s library) for connected organisations. Store install is the entitlement (listed free until commercial terms and Store billing). Secure Mode visitor login is not used — the Tawk property is shared with another team.

# Category

Lettings

# What's new

Documents catalogue with guides, free templates, and Julie’s library videos; Tawk chat with out-of-hours panel matching her livechat schedule.

# What it can do

- Open a signed quick view from the Store
- Browse guides, free templates, and video tutorials from Lettings Advice Service
- Start a Tawk chat with the advice team
- Disconnect wipes this app’s connection secrets from SQLite

# Pre-requisites

Connect from the COHO Store. No Public API capability grants are required for the current chat + document library scope. Tawk property/widget IDs default in code; Hosting may override TAWK_* — the Secure Mode API key is unused.

# Background tasks

None in P0. No product schedules or domain event webhooks. Entitlement is the Store connection only; there is no in-app billing UI.
